This website is designed to help club officers manage meetings, finances, 
and general club information through a simple and easy-to-use interface.

-----------------------------------------------------------------------------
The main page of this website the user will be able to set up monthly meetings,
with the date and the location along with an agenda text. This is a simple, easy 
to use website that uses simple automation by date. Simple automation- After the 
meeting has expired the data of the meeting will transfer to old business. 
This is the same logic for the Finances page. 
Some neat aspects: added homepage feature -The homepage contains general information 
about the club, its purpose, and its mission.This site will also hold the information 
for the club and what it stands as a HARD CODED feauture. This is ideal for 
the(non-techie) end-user to be able to change the front page immediatiey, for 
a limtied time, and still go back to the original site layout without having to 
do many steps.
This site will also have a treasury page. This is a transparent way to see income 
and expense and a summary of all treasury business for the club. The Finances page
also automates to old business with each new input by the user, keeping all 
data together. 

Added - images to new meetings. Great for posters, volunteering work 

Added - documents to new meetings. Great for needing to add addtional information
